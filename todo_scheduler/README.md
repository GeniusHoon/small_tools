# Todo Scheduler

**Todo Scheduler**는 Google Calendar API와 연동하여 윈도우 바탕화면에 항상 띄워둘 수 있는 트렌디한 다크 테마 데스크톱 일정 관리 앱입니다. 최소화 시 작업 표시줄이 아닌 **시스템 트레이(System Tray)**로 숨겨져 백그라운드에서 조용하게 동작하며, 언제든 글로벌 단축키로 빠르게 불러와 일정을 관리할 수 있습니다.

## 주요 기능 (Features)

- **Google Calendar 완벽 연동**: Google Calendar API를 활용하여 일정을 조회하고, 앱 내에서 새로운 일정을 추가하거나 기존 일정을 수정/삭제할 수 있습니다.
- **항상 위에 표시 (Always On Top)**: 투명도 조절 기능을 지원하며 화면 우측에 슬림하게 고정되어 다른 작업을 하면서도 일정을 확인할 수 있습니다.
- **모던 다크 테마 디자인**: 세련된 네이비/블랙 배경과 글래스모피즘(Glassmorphism) 효과, 둥근 모서리 UI를 적용하여 상용 앱과 같은 깔끔한 사용자 경험을 제공합니다.
- **글로벌 단축키 지원**: `Ctrl + F11` 키를 눌러 언제든지 앱 창을 숨기거나 보이게 토글할 수 있습니다.
- **스마트한 특수 일정 관리**: 생일, 공휴일 등 구글에서 자동으로 생성된 읽기 전용 일정은 수정/삭제를 막아 안전하게 보호합니다.

## 사용 방법 (User Guide)

### 1. 초기 설정 (Google API 연동)
1. **Google Cloud Console**에 접속하여 새 프로젝트를 만들고 **Google Calendar API**를 사용 설정(Enable)합니다.
2. `사용자 인증 정보(Credentials)` 탭에서 **OAuth 클라이언트 ID**를 생성합니다. 이때 애플리케이션 유형을 반드시 **'데스크톱 앱'**으로 설정해야 합니다.
3. 생성된 `클라이언트 ID`와 `클라이언트 보안 비밀(Client Secret)` 값을 복사합니다.
4. **Todo Scheduler**를 실행한 뒤, 윈도우 우측 하단의 트레이 아이콘을 우클릭하고 **[설정 (Settings)]** 메뉴로 들어갑니다.
5. 복사한 ID와 비밀번호를 입력하고 저장하면, 자동으로 브라우저가 열리며 구글 로그인 화면이 나타납니다.
6. 권한을 허용해 주시면 연동이 완료됩니다! (이후로는 자동 로그인됩니다.)

### 2. 일정 관리
- **일정 추가**: 앱 상단의 `+` 버튼을 눌러 새 일정의 제목, 메모, 시간을 입력하고 구글 캘린더에 바로 추가할 수 있습니다.
- **일정 수정 및 삭제**: 앱 메인 화면에 띄워진 기존 일정 카드의 우측에 있는 `수정`, `삭제` 버튼을 눌러 즉시 관리할 수 있습니다.
- **새로고침**: 앱 상단의 `↻` 버튼을 누르면 구글 캘린더의 최신 데이터를 수동으로 즉시 동기화합니다. (앱 자체적으로 1시간마다 자동 갱신됩니다.)

### 3. 화면 제어
- 마우스 우클릭 상태에서 드래그하면 원하는 위치로 창을 이동할 수 있습니다. (창 상단을 드래그해도 됩니다.)
- 창 상단의 **투명도 슬라이더**를 좌우로 조절하여 반투명하게 만들 수 있습니다.
- `Ctrl + F11`을 누르거나 일반적인 창 닫기(X) 버튼처럼 동작시켜 창을 숨길 수 있습니다.

### 4. 종료 방법
이 앱은 일반적인 방법으로 꺼지지 않고 항상 백그라운드에 대기하도록 설계되었습니다. 완전히 종료하시려면 **우측 하단 시스템 트레이 아이콘 우클릭 -> [종료]** 버튼을 눌러주세요.

## 빌드 정보 (For Developers)

- Python 3.13 및 PyQt6 기반
- 패키징 명령어: `pyinstaller --noconsole --onefile --windowed --name TodoScheduler main.py`
